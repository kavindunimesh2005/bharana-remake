# NovaShop — Modern E-Commerce Dashboard & Storefront

A responsive e-commerce web application built with **React** and **Vite**, inspired by modern luxury e-commerce and dashboard designs.

## ✨ Features

- **Dashboard Layout**: 3-column responsive layout with Left Navigation, Center Shopping Feed, and Right Cart & Recommendations drawer.
- **Hero Banner**: Gradient hero showcase with carousel slides, call-to-action button, and floating accents.
- **Category Filter**: Quick-filter products by category (Fashion, Beauty, Electronics, Home & Living, Sports).
- **Interactive Flash Sale & Promos**: Live ticking countdown timer (`02:45:18`), Free Shipping, and New Arrivals cards.
- **Product Catalogs**:
  - **Best Deals for You**: Rating stars, discount tags, dynamic hover zoom, and quick add-to-cart.
  - **Recommended for You**: Interactive color swatches selector, live price badges, and add-to-cart buttons.
- **Interactive Cart & Calculations**:
  - Live subtotal, coupon discount, free shipping calculation, and grand total.
  - Quantity controls (`-` / `+`), item removal, and empty state.
  - Promo code verification (`SUMMER10`, `SAVE20`).
- **Modal Flows**:
  - One-click checkout modal with address details and order confirmation.
  - NovaShop VIP Club membership modal.
- **Dark / Light Mode**: Seamless theme switching with custom design tokens.
- **Toast Notifications**: Real-time feedback when liking items, adding to cart, or applying coupons.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kavindunimesh2005/bharana-remake.git
   cd bharana-remake
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run locally:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
